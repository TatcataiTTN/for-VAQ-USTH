Part 1 · Foundations

Ideal and practical op-amps

  • Op-amp = single-ended-output differential amplifier with very high open-loop gain
  • Two inputs: inverting (−) and noninverting (+); one output; dual ±V supply
  • Ideal: Zin = ∞, Zout = 0, Aol = ∞, bandwidth = ∞, CMRR = ∞
ParameterIdealPractical (typical)
Aol∞10⁵–2·10⁵
Zin∞≈ MΩ–GΩ
Zout0≈ 10–100 Ω
CMRR∞≳ 90 dB
📖 Explanation for beginners
An op-amp is an amplifier building block: it takes the difference of two voltages and multiplies it by hundreds of thousands. External resistors set the gain you actually use.
Part 1 · Foundations

Three input modes

  • Single-ended differential: one input grounded, signal on the other
  • Double-ended differential: signal between the two inputs
  • Common mode: same signal on both inputs → output ≈ 0 (noise cancels)
Differential and common-mode gain
Vout = Aol·(V₊ − V₋) + Acm·V_cm
📖 Explanation for beginners
Noise usually hits both wires identically; a differential stage amplifies only the difference, so the noise is rejected.
Part 1 · Foundations

CMRR and the decibel scale

Common-mode rejection ratio
CMRR = Aol / Acm , CMRR(dB) = 20·log₁₀(Aol/Acm)
  • Aolopen-loop gain
  • Acmcommon-mode gain
Example · Problem 5 (Floyd)
Aol = 175 000, Acm = 0.18 → CMRR = 972,222 → 119.8 dB ≈ 120 dB
📖 Explanation for beginners
Bigger CMRR is better. 20 dB is a factor of 10 in voltage, 40 dB is 100, 80 dB is 10,000.

Bias, offset and slew rate

ParameterFormulaMeaning
I_BIAS(I₁ + I₂)/2average input current
I_OS|I₁ − I₂|difference of the two input currents
V_OSinput voltage that nulls the outputinput-stage imbalance

Example · Problems 7–10
I_BIAS = 8.1 μA; I_OS = 0.4 μA; SR = 24 V/15 μs = 1.6 V/μs; −10→+10 V at 0.5 V/μs takes 40 μs
📖 Explanation for beginners
Both inputs always draw a small current; if they differ you get a dc error. Slew rate limits large, fast signals.

Part 2 · Methods

The noninverting amplifier

Noninverting amplifier
Acl(NI) = 1 + Rf/Ri , B = Ri/(Ri + Rf) , Acl ≈ 1/B

With Rf = 100 kΩ, Ri = 4.7 kΩ: Acl = 22.3.

📖 Explanation for beginners
The signal enters the (+) input and a fraction B of the output returns to (−). The (−) input follows (+), so Vout = Vin/B.
Part 2 · Methods

The inverting amplifier

Inverting amplifier
Acl(I) = −Rf/Ri

The inverting input is a “virtual ground”: the current through Ri equals the current through Rf.

📖 Explanation for beginners
Because (−) ≈ 0 V, the input current Vin/Ri flows entirely through Rf, so Vout = −Vin·Rf/Ri. The minus sign means a 180° phase inversion.
Part 2 · Methods

Input/output impedance and the follower

ConfigurationZinZout
Noninverting(1 + B·Aol)·ZinZout / (1 + B·Aol)
Voltage-follower(1 + Aol)·ZinZout / (1 + Aol)
Inverting≈ RiZout / (1 + B·Aol)
Voltage-followerOutput wired straight to (−): Acl = 1, in phase, very large Zin → buffer.
📖 Explanation for beginners
Negative feedback makes the circuit “stiffer”: easy to drive (high Zin) and good at driving loads (low Zout).
Part 2 · Methods

Bandwidth and the gain–bandwidth product

Frequency response
Aol = Aol(mid)/√(1 + (f/fc)²) , θ = −tan⁻¹(f/fc) , fT = Aol(mid)·fc(ol)
Closed loop
fc(cl) = fc(ol)(1 + B·Aol(mid)) , BWcl = BWol(1 + B·Aol(mid)) , fT = Acl·fc(cl)

Roll-off is −20 dB/decade above fc; the gain–bandwidth product stays constant.

📖 Explanation for beginners
Ten times more gain leaves one tenth of the bandwidth: you trade gain for bandwidth.

Part 4 · Pitfalls and extensions

Feedback-resistor faults

FaultSymptom
Rf openNo feedback → gain = Aol → saturation
Ri open (inverting)Signal cannot enter → output ≈ 0
Rf shortedGain = 1 (NI) or 0 (inverting)
📖 Explanation for beginners
“Is the feedback path intact?” is the first question when troubleshooting an op-amp circuit.
Part 4 · Pitfalls and extensions

Bias compensation and offset nulling

Bias-current compensationAdd Rc = Ri‖Rf at the (+) input of an inverting amplifier so both bias-current drops are equal; the remaining output error comes only from I_OS and V_OS.
Compensating resistor
Rc = Ri‖Rf = Ri·Rf/(Ri + Rf)
📖 Explanation for beginners
A small bias current through a large resistor still produces a noticeable dc output error.
Part 4 · Pitfalls and extensions

Two frequency limits: bandwidth and slew rate

  • Small amplitude, high frequency → limited by bandwidth (GBP)
  • Large amplitude, high frequency → limited by slew rate → triangular distortion
  • Both appear as frequency rises; check both
📖 Explanation for beginners
A signal can be “within bandwidth” yet distorted because it changes faster than the slew rate allows.
Part 4 · Pitfalls and extensions

Error from finite Aol

Exact closed-loop gain
Acl = Aol / (1 + B·Aol) → 1/B khi B·Aol ≫ 1

With Aol = 100,000 and B = 1/101: Acl = 100.8981 (versus 101). Error ≈ 0.1 %.

📖 Explanation for beginners
The 1 + Rf/Ri formula assumes a huge Aol; with a low Aol or at high frequency the error grows.

3. History and theory context

Op-amps began in analog computers (summing and integrating); monolithic ICs such as the 741 made them cheap and stable. The core idea is negative feedback: large gain is traded for precision and stability.

4. Aircraft case study (illustrative)

Illustrative: signal conditioning for temperature or pressure sensors — a high-CMRR differential stage rejects common-mode noise on long wires and a follower buffers the signal ahead of the A/D converter. A principle example, not a specific system description.

5. Exam pitfalls

  • Forgetting the “+1” in the noninverting gain; dropping the sign in the inverting gain.
  • Using 10·log instead of 20·log for voltage ratios.
  • Mixing up I_BIAS (average) with I_OS (difference).
  • Unit slips between μs and ms in slew rate.
  • Rf open → gain does NOT become zero but rises to Aol.
