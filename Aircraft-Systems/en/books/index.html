Book map

Which module each chapter of the two available textbooks belongs to. Chapter level; section level comes later. Page numbers are the PRINTED pages (Tooley: PDF page minus 14; Floyd: PDF page minus 1, measured on page headers).

Module ↔ book chapters

ModuleTooley (3rd ed.)Floyd (11e)Note
01: Number SystemsCh.2 Number systems (p.25-38): decimal, binary, octal, hex, ASCIICh.2 Number Systems, Operations, and Codes (p.65-124)Near 1-to-1 match: both books devote exactly one chapter to these same four number systems.
02: Logic Circuits & Boolean AlgebraCh.5 Logic circuits (p.70-94): gates, Boolean algebra, combinational logic, tri-state, monostable/bistable, logic familiesCh.3 Logic Gates (p.125-190) + Ch.4 Boolean Algebra and Logic Simplification (p.191-260); the bistable part is cross-referenced with Ch.7 Latches, Flip-Flops, and Timers (p.387-448)Tooley bundles gates + Boolean algebra + bistables into one chapter; Floyd splits this into three more detailed chapters.
03: Integrated Circuits & MultiplexingCh.8 Integrated circuits (p.139-148) + Ch.9 MSI logic (p.149-164): fan-in/out, decoders, encoders, multiplexersCh.6 Functions of Combinational Logic (p.313-386): decoders, encoders, multiplexers, demultiplexers, comparators; IC fabrication technology is cross-referenced with Ch.15 Integrated Circuit Technologies (p.855+)Tooley splits 'IC technology' (ch.8) and 'MSI applications' (ch.9) into two chapters; Floyd bundles all MSI applications into Ch.6 and keeps fabrication technology separate at the end of the book (Ch.15).
04: Computers & MicroprocessorsCh.6 Computers (p.95-115): computer systems, data storage, backplane bus + Ch.7 The CPU (p.116-138): internal architecture, x86/Pentium/AMD 29050Ch.11 Data Storage (p.627-696): RAM/ROM/Flash memory. Floyd has NO dedicated chapter on CPU/microprocessor architecture: this is the biggest difference between the two books for this module.This module has the WEAKEST match between the two books: Floyd is a pure digital-logic fundamentals text and does not cover computer/CPU architecture in depth like Tooley: the CPU content in this module relies mainly on Tooley.
05: Data BusesCh.4 Data buses (p.53-69): bus rationale, ARINC 429 (electrical/word format/BCD-BNR), other standards (ARINC 629/AFDX/MIL-STD-1553/legacy buses)Ch.13 Data Transmission, §13-6 Bus Basics (PDF p.765), §13-7 Parallel Buses, §13-8 USB, §13-9 Other Serial Buses, §13-10 Bus Interfacing (PDF p.785): GENERAL computer buses, NOT aircraft buses (ARINC 429/629, MIL-STD-1553 and AFDX are not in Floyd).Floyd matches only at the level of general buses (USB, serial, parallel, bus interfacing: Ch.13 §13-6 to 13-10; 19 Floyd questions in the bank, true/false and Self-Test); it has no aircraft buses. ARINC 429/629/AFDX rely on Tooley Ch.4 and the 18-page lecture deck.
06: Electronic DisplaysCh.1 Introduction (p.1-24): flight instruments, EFIS, ECAM/EICAS, cockpit layouts + Ch.11 Displays (p.178-196): CRT, LED/7-segment, LCD + Ch.15 Avionic systems, sections 15.1 ACARS, 15.2 EFIS, 15.3 EICAS/ECAM (p.238-250); 53 MCQs from Ch.1, 11, 15Ch.4 Applied Logic: Seven-Segment Display (p.244-249; problems 62-71, p.256) + Ch.6 section 6-5 decoder/driver 74HC47 and zero suppression (p.338-340) + section 6-8 7-segment multiplexing (p.353). Floyd has NO content on EFIS/ECAM/ACARS or CRT/LCD technology beyond the 7-segment level: most of this module relies on Tooley and the lecture slides.This module has its own lecture deck (36 infographic slides, each read directly). Tooley matches well (three scattered chapters: Ch.1, Ch.11, Ch.15). Floyd matches only at the 7-segment level (Ch.4, Ch.6), so this module's Floyd quiz is small and the essay section has only the 4 odd Applied Logic problems.
07: Software Management ControlCh.13 Software (p.207-217): 13.1 classification, 13.2 certification, 13.3 upgrading (FLS, LSAP, UMS, OSS, DFLD, EEC loading with PDL), 13.4 data verification; 7 MCQs; plus Ch.15 MCQ on navigation database updateCh.2 section 2-12 Error Codes (parity, CRC, Example 2-41; p.109-114) and Ch.11 section 11-11 (ROM checksum test, Figures 11-74 and 11-75). Floyd has NO content on DO-178, software levels or loading aircraft software: it matches only on the data error checking aspect.The main source is the 6-page EASA Part-66 Module 5.13 document (13.1 to 13.6, with Figure 13-1 and 6 questions with answers) plus Tooley ch.13. The module has 2 interactive demos (checksum versus CRC, a DAL level explorer).
08: Fibre OpticsCh.10 Fibre optics (p.165-177): 10.1 advantages, 10.2 propagation (critical angle, numerical aperture, attenuation), 10.3 dispersion and bandwidth, 10.4 practical networks (ARINC 636, cable, connectors), 10.5 components; 20 MCQs (A.10, p.379-380)Ch.13 Data Transmission, section 13-1 Data Transmission Media (p.740-745): optical fiber cable, modes (multimode, single-mode, 50/125, 62.5/125, 8.3/125), link block diagram, connectors; Section Checkup; Problems 5 and 7 (p.793; answers A-27). Floyd has NO critical angle, numerical aperture, attenuation or dispersion: the deeper theory relies on the lecture and Tooley.The 37-slide lecture has four calculation exercises (slides 20, 22, 27, 36); the module solves and verifies them, and only slide 36 has a printed answer. The module has 2 interactive demos (fibre calculator, Snell/TIR ray) and records the 7 mismatches found in the material.
09: EMCCh.14 EMC (p.218-237): 14.1 harmonics and pulse spectrum, 14.2 EMC and avionic equipment, 14.3 spectrum analysis (noise floor, Table 14.1 bands), 14.4 effects, sources and reduction of EMI, 14.5 wiring, 14.6 grounding and bonding; 9 MCQs (A.14, p.381)Floyd has NO EMC chapter. Only partial matches: Ch.13 section 13-1 (cross talk, UTP/STP twisted pairs against EMI, p.741), Ch.6 section 6-11 (VCC-to-ground decoupling, p.364), Ch.15 section 15-3 (noise margin, p.859; Problem 3 p.887). Most of the module relies on Tooley and the lecture.The 46-slide lecture (each slide read) has 3 dB exercise sets (slides 17, 19, 21); all were re-solved and the 10 kW versus 100 kW error on slide 21 was caught. The module has 3 interactive demos (dB and dBm, square-wave Fourier, a real capacitor) and records the mismatches found in the material.
