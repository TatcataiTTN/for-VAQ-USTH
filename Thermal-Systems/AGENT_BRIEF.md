## Property library `build/props/props.py` (P3, gate passed: `.venv/bin/python -I build/verify/verify_props.py` → `FAILS: none`)
Use `sys.path.insert(0, '$P/build/props'); import props` and the venv python. Every lookup returns a dict `{value, unit, table, pdf_page, printed_page, rows_used, method('exact'|'linear'|'bilinear'), suspect, note}`: QUOTE `table` and `printed_page` in solutions. Out-of-range requests raise `PropsRangeError` (no extrapolation).
- Water (A-4 by T, A-5 by P, A-6 superheated, A-7 compressed liquid): `props.sat_T('water', T_C, 'hf')`, `sat_P('water', P_kPa, 'Tsat_C')`, `wet_T/wet_P(sub, ., x, prop)`, `superheated('water', P_MPa, T_C, 'h')`, `superheated_inverse`, `compressed(P_MPa, T_C, prop)`, `quality(sub, by, val, prop, y)`. Columns: `Psat_kPa, Tsat_C, vf, vg, uf, ufg, ug, hf, hfg, hg, sf, sfg, sg`, superheated `v, u, h, s`.
- R-134a (A-11, A-12, A-13): same functions with `'R134a'`.
- Air (A-17 SI, A-17E English units): `props.air(T_K, 'h'|'Pr'|'u'|'vr'|'s0')`, `air(T_R, ..., system='E')`, inverse `air_inverse('Pr', 11.09)` (linear in the column, as students do).
- Gases per kmol (A-18…A-25: N2, O2, CO2, CO, H2, H2O, OH): `gas_kmol(gas, T_K, 'h'|'u'|'s0')`, `gas_kmol_inverse`; cp(T) tables: `cp_T(gas, T_K, 'cp'|'cv'|'k')`; constants `critical(sub, 'M'|'R'|'Tcr'|'Pcr')` (A-1).
- Combustion: `formation('CO2(g)', 'hf0'|'gf0'|'s0')` (A-26, kJ/kmol), `fuel('octane', 'HHV'|'LHV'|'M'|'hfg')` (A-27).
- Isentropic flow k = 1.4 (A-32): `isentropic(Ma, 'Ma_star'|'A_Astar'|'P_P0'|'rho_rho0'|'T_T0')`, `isentropic_inverse(prop, value, branch='sub'|'sup')`.
Cautions measured by the P3 gate (read `data/props/crosscheck.json`, `data/props/book_errata.json`):
- Linear interpolation of the printed tables is the BOOK method; use it for 'table route' answers and quote the rows. Its error against the exact equation of state can be large between sparse rows (superheated v between P blocks +12 % … +80 %; A-32 between Ma 3 and 5 +120 %; saturated P between rows ≤ 1.4 %): the library attaches a warning. Do not use a table route in a question whose distractor spacing is smaller than that error.
- Cross-check route (iapws IF97, CoolProp R134a with ASHRAE reference, CoolProp Air ideal-gas limit) agrees with the printed tables only to ~0.1–2 % (2760 of 6988 cells inside the half-last-digit rounding; the rest differ by up to 11.9 % for water near the critical point, 2.4 % R-134a, 1.9 % air). Cause for R-134a and air: not identified. So in `verify_mNN.py` compare table-route vs library with an EXPLICIT tolerance (e.g. 0.5 % on enthalpy DIFFERENCES away from the critical point; COP 0.2 %), say so in the solution's `assume`, and never tune a tolerance to hide a gap.
- `suspect: true` cells are printed-book errors (43 in `book_errata.json`: e.g. A-17 h(550 K) printed 555.74, expected 554.74; v_r(1040 K) 23.29 vs ≈22.4; P_r(630 K); A-17E P_r(2150 R) 223.5 vs ≈233.5; A-20 h(1480 K) 66 911 vs 69 911; A-32 ρ/ρ0 at Ma 3 0.0760 vs 0.0762): the library returns the printed number AND the flag; avoid these rows in questions, or use them to ask about the error.
Not done (do not use): A-3, A-8, A-16, A-28, A-33, A-34; English-unit tables other than A-17E; every chart (T–s, Mollier, P–h, psychrometric). Dew point needs P_sat(T) of water: use `sat_T('water', T, 'Psat_kPa')`.
