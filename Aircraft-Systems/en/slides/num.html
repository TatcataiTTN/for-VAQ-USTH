Slide 4: Introduction (analog and digital representation)

Analog representation is a continuous value with respect to time and characterises an analog signal. Digital representation is a discrete value with respect to time and characterises a digital signal. Figures: an analog sine wave between +120 V and -120 V against time, captioned "analog signal: it consists of a continuously changing voltage level"; a digital pulse train 0 1 0 0 1 0 1 1 between 0 V and +5 V, captioned "Digital signal: it consists of series of discrete voltage that alternate between logic 0 and 1". Advantages of digital compared to analog: possibility of encoding of digital data (safety); only two levels of amplitude, easier reconstitution of the digital signal (reliability); precise value always in time (reliability); compatible with computers; stable and more rapid than analog system.

Numbers: sóng tương tự +120 V đến -120 V; tín hiệu số 0 V và +5 V, chuỗi 0 1 0 0 1 0 1 1

Slide 5: Introduction (aircraft digital systems)

Bullets: aircraft rely more and more on digital systems; information within an aircraft digital system is a sequence of 1s and 0s known as binary data; digital quantities can be kept at very high accuracy and measured and manipulated at very high speed; the binary system is widely used in digital computers and digital electronics. Figures: an aircraft outline with flight-control data buses (primary flight computers, autopilot director computers, air data reference unit, actuator control electronics) and systems data buses (engine data interface, aircraft information management system, flap/slat electronics unit, proximity electronics unit); a digital signal drawn as pulses of 1 and 0; a block diagram: input (a temperature, pressure, air flow, linear motion or rotation) goes through sensing the signal, conditioning the signal, converting the signal analog-to-digital, then digital system processing, then converting digital-to-analog, conditioning, transducing to a useful output (a solenoid, heater, motor or cooler); the converted signals are an electrical voltage or current.

Slide 7: Decimal number system

Decimal numbers are used every day. The decimal system consists of ten digits, 0 through 9. The position of each digit indicates the magnitude of the quantity represented and can be assigned a weight. The weights for whole numbers are positive powers of ten that increase from right to left. Example: express the decimal number 52 as a sum of each digit: the digit 5 has a weight of 10 (10^1) and the digit 2 has a weight of 1 (10^0), so 52 = (5 x 10^1) + (2 x 10^0) = 50 + 2.

Formulas: 52 = (5 x 10^1) + (2 x 10^0) = 50 + 2

Slide 9: Binary numbers (weights and binary to decimal)

The binary system has two digits, 0 and 1 (bits). Weights are powers of two and the position of a 1 or 0 gives its weight. The rightmost bit is the LSB, the leftmost is the MSB (figure: binary number 110100 with MSB and LSB arrows). Binary to decimal: add the weights of the bits that are 1 and discard the weights of the bits that are 0. Example: 11011010 = (1x2^7)+(1x2^6)+(0x2^5)+(1x2^4)+(1x2^3)+(0x2^2)+(1x2^1)+(0x2^0) = 128+64+16+8+2 = 218. Table of binary weights: 2^8 = 256, 2^7 = 128, 2^6 = 64, 2^5 = 32, 2^4 = 16, 2^3 = 8, 2^2 = 4, 2^1 = 2, 2^0 = 1.

Formulas: 11011010 = 2^7 + 2^6 + 2^4 + 2^3 + 2^1 = 128 + 64 + 16 + 8 + 2 = 218

Numbers: 11011010 nhị phân = 218 thập phân

Checked by computation: 128+64+16+8+2 = 218. Đúng.

Slide 11: Binary numbers (counting)

Counting in binary: begin 0, 1; a second position is required: 10, 11; then a third position: 100, 101, 110, 111. With n bits you can count up to 2^n - 1; example: with five bits you can count from zero to thirty-one. Table: a binary count of zero through fifteen in four bits (0 = 0000 ... 15 = 1111).

Formulas: 2^n - 1

Numbers: 5 bit: 0 đến 31; 4 bit: 0000 đến 1111 (0 đến 15)

Slide 12: Binary numbers (decimal to binary: sum of weights)

Decimal to binary conversion by two methods: sum of weights and repeated division by 2. Sum of weights: find the set of binary weights whose sum equals the decimal number. Example: 11 = 8 + 2 + 1 = 2^3 + 2^1 + 2^0, so the binary number of decimal 11 is 1011. The table of binary weights 256 down to 1 is repeated.

Formulas: 11 = 8 + 2 + 1 = 2^3 + 2^1 + 2^0

Numbers: 11 thập phân = 1011 nhị phân

Slide 13: Binary numbers (decimal to binary: repeated division by 2)

Repeated division by 2 method. Step 1: divide 11 by 2. Step 2: divide each resulting quotient by 2 until there is a 0 whole-number quotient. The remainders form the binary number; the first remainder is the least significant bit and the last is the most significant bit. Worked: 11/2 = 5 remainder 1 (low significant bit); 5/2 = 2 remainder 1; 2/2 = 1 remainder 0; 1/2 = 0 remainder 1 (most significant bit); stop when the whole-number quotient is 0. Binary number: 1011.

Numbers: 11 chia 2 liên tiếp cho 1011

Checked by computation: 11 = 1011 nhị phân. Đúng.

Slide 16: Hexadecimal numbers

Hexadecimal has 16 characters and is used to display or write binary numbers. Computers and microprocessors understand only 1s and 0s, which is needed when programming in machine language; writing a sixteen-bit instruction in 1s and 0s is far less efficient than in hexadecimal. Hexadecimal is widely used in computer and microprocessor applications. The system uses the digits 0-9 and the letters A-F. Counting with two hexadecimal digits reaches FF16, decimal 255: 0, 1, 2 ... 9, A, B, C, D, E, F, 10, 11, 12, 13 ... 19, 1A, 1B, 1C, 1D, 1E, 1F. Table of decimal 0-15 with binary 0000-1111 and hex 0-F.

Numbers: FF16 = 255

Checked by computation: FF16 = 15x16 + 15 = 255. Đúng.

Slide 18: Hexadecimal numbers (binary to hexadecimal)

Binary to hexadecimal: break the binary number into 4-bit groups starting at the rightmost bit and replace each group with the equivalent hexadecimal symbol. Example 1: 110101011110 is grouped 1101 0101 1110 and equals D5E (base 16). Example 2: 1101011110, add two zeros on the left to complete a 4-bit group, 0011 0101 1110, equals 35E (base 16).

Numbers: 110101011110 = D5E16; 1101011110 = 35E16

Slide 20: Octal number

The octal system gives a convenient way to express binary numbers and codes. It has eight digits, 0 to 7. Counting is like decimal except that 8 and 9 are not used: 0, 1, 2, 3, 4, 5, 6, 7, 10, 11, 12, 13, 14, 15, 16, 17, 20, 21, ... Subscript 8 marks octal; example: 14 in octal equals 12 in decimal and C in hexadecimal. Octal to decimal: multiply each digit by its weight and sum; example 1325 (base 8): weights 8^3, 8^2, 8^1, 8^0, so 1x8^3 + 3x8^2 + 2x8^1 + 5x8^0 = 512 + 192 + 16 + 5 = 725 (decimal).

Formulas: 1325_8 = 1x8^3 + 3x8^2 + 2x8^1 + 5x8^0 = 512 + 192 + 16 + 5 = 725_10

Numbers: 14_8 = 12_10 = C_16; 1325_8 = 725_10

Checked by computation: 14 bát phân = 8 + 4 = 12; 512 + 192 + 16 + 5 = 725. Đúng.

Slide 22: Octal number (decimal to octal and octal to binary)

Octal to binary: replace each octal digit with three bits; table 0 = 000, 1 = 001, 2 = 010, 3 = 011, 4 = 100, 5 = 101, 6 = 110, 7 = 111.

Slide 25: Binary coded decimal

BCD is a way to express each decimal digit with a binary code. Applications: digital clocks, digital thermometers, digital meters and other devices with seven-segment displays, which typically use BCD to simplify displaying decimal numbers. There are only ten code groups in the BCD system so converting between decimal and BCD is easy. Each decimal digit 0 to 9 is represented by a four-bit binary code. Table: 0 = 0000, 1 = 0001, 2 = 0010, 3 = 0011, 4 = 0100, 5 = 0101, 6 = 0110, 7 = 0111, 8 = 1000, 9 = 1001.

Numbers: 0 = 0000 ... 9 = 1001

Checked by computation: Đã kiểm bảng 0 đến 9: đúng.
